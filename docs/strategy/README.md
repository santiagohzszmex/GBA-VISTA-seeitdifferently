# Registro estratégico de GBA

Este directorio conserva las decisiones que definen la etapa actual de GBA.
No reemplaza la documentación técnica de cada producto: establece su contexto,
propiedad y relación con el resto de la organización.

## Documentos vigentes

- [Modelo operativo de GBA](./GBA_OPERATING_MODEL.md)
- [Cierre de GlobalBank](./GLOBALBANK_SUNSET.md)
- [Carta fundacional de ANIMA](./ANIMA_CHARTER.md)

## Decisión principal

Desde el 31 de julio de 2026, GBA funciona como nombre propio de la
organización. Ya no se presenta como abreviatura de GlobalBank Alliance.

GlobalBank y GlobalBank Alliance son proyectos concluidos. No forman parte del
mapa operativo, financiero ni tecnológico vigente.

## Regla de actualización

Toda decisión que cambie la propiedad de un producto, autorice una inversión o
modifique el propósito de una unidad debe registrarse aquí antes de anunciarse
en una GBA Keynote.
